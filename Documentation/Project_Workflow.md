# Project Workflow

1. Load retail CSV into HDFS.
2. Create Hive database and raw external table.
3. Clean data and store analytical data in ORC.
4. Run product-wise, regional and monthly Hive analytics.
5. Use Pig to filter, group, aggregate and sort data.
6. Identify top products and regional performance.
7. Apply optimization concepts such as partitioning, bucketing and ORC.
8. Prepare business recommendations and final report.

The scripts are reconstructed from the project specification and available project execution/report evidence.
